# I18n guide (English / Bahasa Indonesia)

The UI ships in **English** by default. **Bahasa Indonesia** is a full second language, switchable in
**Settings → General** (and on the license gate). The choice applies instantly — no restart — and is
stored in `localStorage` under `bits.language`. It is a UI preference only; it is not stored in the
SQLite settings table and is never sent anywhere.

## How it works

- Core: `src/i18n/index.tsx`
  - `useI18n()` → `{ language, setLanguage, t }` for React components.
  - `translate(key, fallback, params?)` for non-React modules (`format.ts`, `api.ts`).
  - `localeTag()` → `"en-US"` / `"id-ID"` for `Intl` formatting.
- Dictionary: `src/i18n/locales/id/*.ts`, one file per namespace, merged at build time via
  `import.meta.glob("./locales/id/*.ts", { eager: true })`. There is **no English dictionary** — the
  English text is the inline fallback in the call site.

### Calling `t`

```tsx
const { t } = useI18n();

t("storyboards.newTitle", "New storyboard")
t("dashboard.runningQueued", "{running} running · {queued} queued", { running, queued })
// Plurals: two keys, ...One / ...Many
t("dashboard.enabledWorkflowsOne", "{count} enabled workflow", { count })
t("dashboard.enabledWorkflowsMany", "{count} enabled workflows", { count })
```

`{placeholder}` interpolation works in both languages. Outside React:

```ts
import { translate } from "../i18n";
translate("common.operationFailed", "The operation failed");
```

### Rules

1. **Every user-visible string in `src/**` goes through `t()` or `translate()`.** The English
   fallback is the source of truth; the key must exist in `locales/id/<namespace>.ts`.
2. **Namespace = page or domain.** Shared strings live in `common` (Save/Cancel/Retry, statuses,
   nav, license, onboarding, language). Reuse `common.*` instead of duplicating.
3. **Statuses**: never hard-code status labels. Use `humanStatus(status)` from `lib/format.ts`
   (it looks up `status.<value>` and falls back to `defaultStatusLabel`), or
   `t("status.<value>", ...)`.
4. **Do not translate**: brand names (BITS AI Video Creator, BITS License Manager), provider names,
   technical tokens (`ai.api_key`, `tts.api_key`, cron, HTTP, JSON, SQLite), code/identifiers, and
   backend error messages (those come from Rust and stay English).
5. **Keys are stable identifiers.** Changing a key is a breaking change for translators; add a new
   key instead.
6. Keep `t()` fallback text and the `id` value meaning-identical; Indonesian uses formal-but-warm
   tone (Anda-form).

## Coverage gate

`src/i18n/coverage.test.ts` scans `src/**` for `t("key"` / `translate("key"` calls and fails the
test suite if any key is missing from the Indonesian dictionary. `src/i18n/i18n.test.tsx` asserts
the language switch applies instantly. Run `npm test` after adding keys.

## Adding a language later

1. Create `src/i18n/locales/<lang>/*.ts` and merge it in `src/i18n/index.tsx` alongside `id`.
2. Extend the `Language` type and `localeTag()`.
3. Add the option to `LanguageToggle` and Settings.

## Known non-translated spots (intentional)

- `lib/studio.ts` default scene titles (`"Scene 3"`) are data-layer defaults persisted into the
  database; tests assert them. Translating them would rewrite user data semantics — left English.
- Backend (Rust) error strings and the local HTTP API responses.
